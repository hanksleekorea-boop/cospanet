# 코스파넷 저숙련 AI 무해석 5단계 상세개발계획 v3.3

## 사용 규칙

이 문서는 코드를 바로 수정하라는 명령이 아니다. 각 단계의 진입·종료조건과 96필드 카드, 시험, 증거를 채운 뒤 별도 승인된 개발 작업에서 실행한다. 정확히 5단계를 사용한다.

## STAGE-1-BASELINE — 현행 파악·자료 보존·안전 기반

진입: 프로젝트·Git·정본·공개 URL 식별. 종료: 정본·범위·백업·실행·검사 기준선 재현. D1/OAuth/DNS 값은 추측하지 않고 Discovery 카드로 확인한다.

## STAGE-2-FOUNDATION — 구조·데이터·권한·공통 UI 기반

진입: STAGE-1 통과. 종료: 계정·권한·저장·공통 상태·모바일/PC 계약이 격리 시험 가능. 실제 D1 binding 전에는 성공 저장을 표시하지 않는다.

## STAGE-3-CORE — 핵심 사용자 여정과 필수 기능

진입: STAGE-2 통과. 종료: 발견→상세→공유/저장→가계부→삭제의 정상·빈·로딩·오류·복구 흐름이 인수 기준 통과. 콘텐츠 권리·신선도·지점·알림을 포함한다.

## STAGE-4-QUALITY — 전 분야 품질·통합·내구성

진입: STAGE-3 통과. 종료: 모바일·PC·성능·접근성·보안·광고·오프라인·관측 조건 통과. 자동 검사와 사람 시험을 구분한다.

## STAGE-5-RELEASE — 공개 준비·복구·인수·안정화

진입: STAGE-4 통과. 종료: 실제 지정 도메인·OAuth·D1·콘텐츠·운영자·Android·법률·복구 증거가 모두 연결되고 남은 차단 항목이 0이다.

## 절대 순서

`DISCOVERY → BASELINE → FOUNDATION → CORE → QUALITY → RELEASE`. 단계 건너뛰기와 “알아서” 실행은 금지한다. 상세 24절과 폴더별 계약은 각 `stage-0N/README.md`를 따른다.

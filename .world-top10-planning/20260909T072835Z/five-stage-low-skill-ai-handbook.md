# 저숙련 AI 무해석 5단계 핸드북

## 읽는 법

각 단계 README의 24절을 위에서 아래로 읽고, `DISCOVERY` 카드가 끝나기 전에는 `READY` 카드를 시작하지 않는다. 모르는 파일·기호·명령은 추측하지 말고 지정된 discovery 명령의 결과를 채운다.

## 공통 실행 규칙

1. 시작 폴더를 항상 프로젝트 절대경로로 확인한다.
2. 시작 전 파일 바이트·SHA-256·Git 상태를 보관한다.
3. 한 미세 단계는 한 파일·한 변화만 수행한다.
4. 각 단계 직후 가장 작은 확인 명령을 실행한다.
5. 성공·실패 출력 예시와 실제 출력이 다르면 중단한다.
6. 정상·빈·로딩·오류·권한·오프라인·복구를 모두 시험한다.
7. 외부 계정·비밀값·비용·DNS·기기 조작은 사람 행동 패킷으로 되돌린다.
8. 계획·가상·역사 자료를 구현·실사용·현재 자료로 승격하지 않는다.

## 완료 문장

“파일이 있다”가 아니라 “시험 ID와 증거 경로가 있는 인수조건을 통과했다”라고만 완료를 쓴다. 외부 관문이 하나라도 미평가이면 해당 단계는 `BLOCKED_EXTERNAL`이다.

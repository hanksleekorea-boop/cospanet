# 서비스 기준선

코스파넷은 일본의 온라인·오프라인 생활비 절약 정보를 AI와 사용자 제보로 모아 보여 주고, 가계부·절약 분석·포인트 구조를 결합한 서비스다. 핵심 이용 흐름은 `발견 → 조건 확인 → 저장/공유 → 실제 사용 후 관측 → 가계부·절약 조언`이다.

현재 확정된 강점은 모바일·PC·PWA UI, 검색·필터, 굿딜 카드, 로컬 가계부·절약 계산, 포인트·광고 정책 구조, 자동검사다. 현재 확정되지 않은 핵심은 실제 공동 서버 저장, Google OAuth 왕복, D1 바인딩, 실제 콘텐츠, 운영·법률·광고 승인, 현재 Android 시험이다.

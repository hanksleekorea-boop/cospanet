# v3.2 10배 작업량 미달·대체 심층 작업

## 판정

`X10_PARTIAL_SCOPE`이다. 10배 계약을 달성했다고 선언하지 않는다. 후보 800개, 원자 지표 1,600개, 의사결정 400칸, 경계 사례 10,000건, 틀린 표본 100건을 실제로 수행하지 않았기 때문이다.

## 미달을 숨기지 않는 이유

- 기존 비교군은 2026-08-24 자료를 재사용한 10개 역사 후보다. 현재 순위·시장점유율을 의미하지 않는다.
- 핵심 외부 경로(D1, OAuth, DNS, 실제 콘텐츠·운영자)가 막혀 공개판 관찰을 최신 증거로 승격할 수 없다.
- 미확인을 0점이나 완료로 바꾸지 않았다.

## 대체 심층 작업

1. 기존 20개 갭을 P0/P1/P2와 의존성으로 분해했다.
2. 20개 결정 셀에 근거·인수조건·결정권자를 연결했다.
3. 32개 비교 지표의 중복 방지용 metric family를 고정했다.
4. 핵심 사용자 여정의 정상·빈·오래됨·권한거부·오프라인·복구 변형을 시험계약으로 남겼다.
5. 10,000건 경계 사례를 재현할 seed·층화·예상 거부율을 고정했다.

이 대체 작업은 분석 품질을 높이지만, 부족한 실제 조사 수량을 대체해 `X10_COMPLETE`로 만들지는 않는다.

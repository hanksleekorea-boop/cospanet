# 코스파넷 통합 제품기획서 v3.2 실행본

## 1. 제품 정의

코스파넷은 일본 전역에서 온라인·오프라인 굿딜을 찾고, 출처·확인시각·지역·조건을 이해하며, 사용자가 직접 검증 가능한 정보를 공유하고, 개인 가계부와 절약 행동을 연결하는 무료 우선 서비스다. 딜캐치는 굿딜 발견·공유 영역이며 공동구매만을 뜻하지 않는다.

## 2. 핵심 사용자 결과

1. 30초 안에 지금 이용 가능한 절약 기회를 찾는다.
2. 가격·조건·지점·유효기간·출처를 보고 잘못된 딜을 피한다.
3. 링크·사진·매장 관측을 간단히 공유하고 검증된 기여 포인트를 받는다.
4. 포인트는 회원 간 양도만 가능하며 현금 출금·환전·상품 대가 지급은 하지 않는다.
5. 실제 확정 지출과 예상 절약을 구분한 가계부를 통해 다음 행동을 선택한다.

## 3. 하지 않는 일

주문·결제·배송 중개, 현금성 포인트, 미허가 자동 수집, 법률·세무 자문, 개인 가계부 원문 광고 타기팅, 운영자 검수 없는 자동 공개를 하지 않는다.

## 4. 신뢰 모델

모든 콘텐츠 카드에 `출처 유형`, `확인시각`, `만료/재확인`, `자가신고/외부검증`, `광고/자연 결과`를 표시한다. 미확인은 미확인으로, 실패는 실패로 기록한다.

## 5. 정보 구조

- 홈: 지역·카테고리·예산 입력, 오늘의 검증된 딜
- 탐색: 온라인/매장/공공혜택/교통/식비/생활비 필터
- 상세: 총비용, 조건, 위치, 확인시각, 출처, 신고·정정
- 공유: 링크·사진·가격·지점·관측시각, 임시저장, 검토 제출
- 가계부: 확정 지출, 반복비, 절약 후보, 예상액과 확정액 분리
- 내 계정: 저장·포인트·프리미엄 해제·삭제·내보내기
- 운영: 검토·신고·이의·철회·복구·품질 지표

## 6. 계정·저장

WeSaver Google OAuth는 state/nonce/PKCE와 허용 callback 검사를 통과해야 한다. 계정별 D1 키를 강제하고, 로그아웃·삭제·복구 범위를 공개한다. D1 바인딩 전에는 성공처럼 보이는 시연 데이터를 제공하지 않는다.

## 7. 콘텐츠 수명주기

출처 등록 → 권리 확인 → 스냅샷 지문 → 운영 검토 → 공개 → 만료/재확인 → 정정/철회 → 감사 보존의 순서다. 실제 승인 출처가 없으면 콘텐츠 목표 수량을 달성한 것으로 계산하지 않는다.

## 8. 개인화·가계부

추천은 지역·예산·선택 카테고리의 최소 정보로 계산하고 근거·초기화·거부를 제공한다. 가계부 원문은 서비스 공개 콘텐츠와 별도 저장·권한으로 관리하며, 예상 절약액은 지출·포인트·광고 수익으로 저장하지 않는다.

## 9. 광고·포인트

AdSense 등 광고는 게시자 승인·CMP·지역 동의·표식이 확인된 뒤에만 켠다. 자연 결과·제휴·광고를 시각적으로 분리하고 광고 off 경로를 제공한다. 포인트는 비현금 내부 권리로 제한한다.

## 10. Outcome Frontier 가설

- H1: 딜 조건과 실제 확정 지출을 연결하면 단순 목록보다 재방문·실행률이 높아진다.
- H2: 미확인·광고·관측을 분리하면 잘못된 구매 판단이 줄어든다.
- H3: “왜 이 딜이 나에게 맞는가”를 지역·예산·유효기간 근거로 설명하면 검색 시간이 단축된다.

각 가설은 실제 동의 사용자 파일럿으로 반증해야 하며, 가상 1,000명 결과로 승인하지 않는다.

## 11. 우선 제품 결정

P0는 D1/OAuth/DNS/콘텐츠 권리/운영 주체/Android 인수다. P1은 신선도·알림·지점·광고 CMP·복구다. P2는 개인화·포인트·가계부 파일럿·수익 실험이다.

## 12. 성공 지표

첫 가치까지 시간, 조건 이해도, 잘못된 딜 신고율, 저장→실행률, 만료 노출률, 정정 처리시간, 계정 삭제 완료율, API 오류율, LCP p75/CLS, 접근성 완주율을 별도로 측정한다. 단일 99% 점수는 사용하지 않는다.

## 13. 인수 조건

실제 A/B 계정 종단, 현재 Android 한 대, 실제 콘텐츠 권리·운영자·문의, 광고 동의, 삭제·복구, 법률 표면을 모두 증거로 확인할 때만 무료 상용 출시를 판정한다.

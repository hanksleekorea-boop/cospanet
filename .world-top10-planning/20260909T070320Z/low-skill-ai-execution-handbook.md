# 저숙련 AI용 실행 핸드북

## 절대 규칙

1. 이 문서의 `PLANNED`, `BLOCKED_EXTERNAL`, `NOT_RUN`을 `DONE`으로 바꾸지 않는다.
2. 비밀값은 환경변수/secret reference만 사용하고 원문을 출력하지 않는다.
3. 사용자 계정 자료는 소유자 ID로 필터링하고 타 계정 조회를 항상 거부한다.
4. 콘텐츠는 출처·확인시각·만료·권리·검수 없이는 공개하지 않는다.
5. 예상 절약액을 실제 지출이나 현금성 포인트로 저장하지 않는다.

## 작업 실행 형식

각 작업은 `목표 → 입력 → 수정 파일 → 명령 → 정상 결과 → 실패 결과 → 되돌리기 → 증거 ID` 순으로 작성한다. 수정 전 파일 지문과 Git 상태를 저장하고, 겹친 사용자 변경은 patch로만 보존한다.

## 단계별 최소 절차

- 1단계: D1 binding과 Google OAuth 설정을 외부 관리자가 확정한 뒤 로컬/API/브라우저 A/B를 순서대로 실행한다.
- 2단계: 신선도·알림·가계부 파일럿을 실제 동의와 분리해 검증한다.
- 3단계: 권리 승인 출처·지역 지점·운영 훈련을 누적 증거로 등록한다.
- 4단계: 광고·개인화·도약 기능은 자연 결과와 시각적으로 분리한다.
- 5단계: Android·접근성·복구·법률·운영 인수 후에만 공개 완료를 판정한다.

## 금지되는 shortcuts

가상 사용자 결과를 실제 사용자로 표현, HTTP 200을 OAuth 성공으로 표현, 계획 문서의 체크를 구현 완료로 표현, 시장 평균을 자사 실측값으로 표현, `null`을 0점으로 계산하는 행위는 모두 실패다.

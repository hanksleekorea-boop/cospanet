# 코스파넷 통합 5단계 상세개발계획 v3.2

## 공통 작업 계약

모든 작업은 `목표 사용자 결과 → 입력 → 수정 후보 → 명령 → 정상/실패 결과 → 시험 ID → 증거 ID → 되돌리기` 순서로 기록한다. 외부 권한이 필요한 작업은 코드 완료와 운영 완료를 분리한다.

## 1단계 — 기준선 고정·위험 제거·기본 상용 흐름

목표는 비로그인 탐색과 안전한 로그인·저장·공유의 최소 흐름이다.

- D1 binding 경로를 확정하고 migration checksum을 확인한다.
- WeSaver OAuth origin/callback/state/nonce/PKCE를 연결한다.
- 계정별 저장·조회·삭제 API를 owner key로 제한한다.
- 온라인·매장 제보 필수 필드와 검토 전 공개 차단을 적용한다.
- 신고·이의·삭제·복구 운영자 역할과 감사로그를 연결한다.
- `kospanet.scanners.cc` DNS/Worker route를 검증한다.
- 유휴 Android 한 대에서 Chrome·PWA 기본 흐름을 실행한다.

종료 조건: A/B 공개 종단, 지정 도메인 HTTPS, OAuth 왕복, D1 재조회, 실제 운영자 사건 1건, 실기기 기본 흐름이 모두 증거로 남는다.

## 2단계 — 핵심 여정·신선도·가계부

- 지역·지점·카테고리 정규화를 적용한다.
- 확인시각·만료·재확인 대기열과 설명 배지를 제공한다.
- 저장 검색·알림함·동의·해제를 구현한다.
- 확정 지출과 예상 절약 조언을 분리한다.
- 실제 동의 파일럿에서 2주 행동 변화를 측정한다.

종료 조건: 만료 딜 오노출률, 알림 중복률, 가계부 계산 오류율, 개인정보 분리 검증값을 운영 대시보드에 기록한다.

## 3단계 — 콘텐츠·운영·전국 확장

- 공식·허가 공급자와 사진/OCR 수집 계약을 운영한다.
- 출처 스냅샷·권리·철회·재검토를 누적한다.
- 47지역·지점·일본어 콘텐츠를 실제 운영자가 검수한다.
- 모더레이션 5종 사건을 훈련하고 SLA를 측정한다.
- 백업·복구와 자료 내보내기·삭제를 반복한다.

종료 조건: 실제 콘텐츠·운영자·권리·철회·30일 운영 증거가 있다.

## 4단계 — 검증 가능한 차별화

- 가계부와 딜의 “이번 달 실제 절약 행동” 연결을 실험한다.
- 톱10도 해결하지 못한 불확실성(지역 품절, 조건 충돌, 광고 혼동)을 설명 가능한 상태 모델로 개선한다.
- 개인화 이유·초기화·거부를 제공한다.
- 자연 결과·제휴·광고를 분리하고 광고 동의율·off율을 측정한다.

종료 조건: H1~H3 중 최소 하나가 실제 사용자 결과로 개선되고, 반증 조건도 기록된다.

## 5단계 — 상용 품질·전체 검증·출시 인수

- Android·iOS/모바일 웹·PC·PWA의 지원 범위를 명시한다.
- TalkBack/Narrator 사람 시험과 키보드·고대비·언어 시험을 완료한다.
- LCP/CLS/TBT p75, 오류·복구·알림·삭제를 반복 측정한다.
- 약관·개인정보·운영자 신원·문의·광고 공개를 실제 값으로 채운다.
- 백업 복원·롤백·장애 공지·비용 상한을 리허설한다.

최종 인수: 필수 조건 미평가·미확인 0, 외부 행동 패킷 완료, 공개 URL 실제 200, 실기기·사람·운영·법률 증거가 모두 연결될 때만 `READY`다.
